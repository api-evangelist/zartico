# Zartico

> Zartico is a Salt Lake City based destination-intelligence software company, founded in 2019,
> that operates the Zartico Destination Operating System (ZDOS) for destination marketing and
> management organizations, states, airports, attractions and ski resorts. It fuses daily
> geolocation observations, credit-card spending data, lodging and short-term-rental data, event
> demand and DMO digital analytics into one integrated data model.

## What Zartico publishes for machines

Zartico has NO developer portal, NO REST API reference, NO OpenAPI, NO GraphQL endpoint, NO
webhooks, NO AsyncAPI, NO MCP server, NO agent card and NO published SDK. An agent looking for a
callable Zartico product API will not find one; access to ZDOS is through the browser
application after a sales conversation.

Two machine-readable surfaces do exist and are anonymously readable:

- OGC Web Services (WMS 1.3.0, WFS 2.0.0, WCS 2.0.1):
  https://geoserver.zartico.com/geoserver/ows
  The GetCapabilities documents ARE the contract. 34 WMS layers, 27 WFS feature types across the
  `zartographer` and `regions_app` workspaces - client boundaries, client regions, census tracts,
  county subdivisions, incorporated places, ZCTA and state/county boundaries, points of interest.
  Fees: none. AccessConstraints: none.
- OpenID Connect / OAuth 2.0 discovery (Okta):
  https://login.zartico.com/.well-known/openid-configuration
  https://platform.zartico.com/.well-known/openid-configuration
  Identity metadata for the ZDOS applications. There is no resource-server API behind them that a
  third party can call, and no Zartico-authored scopes - the seven OIDC scopes plus Okta's own
  org-management defaults.

## How customers actually integrate

Integration with Zartico is INBOUND, not outbound. A destination grants Zartico read access to
its own systems rather than calling a Zartico API:

- Google Analytics: grant read access to the Zartico account
  https://support.zartico.com/integrate-google-analytics
- Ad server (Google Campaign Manager): add data@zartico.com as a reporting user
  https://support.zartico.com/integrate-your-ad-server
- Website attribution: deploy a per-customer geolocation pixel via Google Tag Manager
  https://support.zartico.com/integrate-zartico-website-attribution
